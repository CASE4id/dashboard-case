CEK DATA

Periksa file Excel sebelum diunggah ke situs · Check an Excel file before uploading

Cara pakai / How to use

  1. Siapkan file Excel data tahun baru dengan nama statistik-pln-TAHUN.xlsx (mis. statistik-pln-2026.xlsx).
  2. Seret file ke kotak di bawah, atau klik untuk memilih file. File tidak diunggah ke mana pun; pemeriksaan berjalan di browser Anda.
  3. Jika hasilnya ✔ SIAP DIUNGGAH, lanjutkan ke langkah unggah di PANDUAN-UPDATE-DATA. Jika ada ✖ kesalahan, perbaiki di Excel lalu cek ulang.
